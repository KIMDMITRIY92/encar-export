# ENCAR · Калькулятор ввоза — Telegram Mini App

Считает полную стоимость ввоза автомобиля из Кореи в Россию, Казахстан и Беларусь: таможенные платежи, утилизационный сбор, акцизы, регистрацию, логистику. Открывается из Telegram как мини-приложение.

## Состав

| Файл | Что делает |
|---|---|
| `index.html` | само мини-приложение, один файл |
| `rates.js` | **справочник ставок** — единственное место, где правятся ставки |
| `fx.js` | курсы центробанков, обновляется автоматически, руками не править |
| `update-fx.mjs` | скрипт, который забирает курсы и пересобирает `fx.js` |
| `.github/workflows/fx.yml` | ежедневный запуск скрипта в 06:10 UTC + кнопка «запустить вручную» |

## Как опубликовать

1. Залить всё в репозиторий, ветка `main`.
2. **Settings → Pages** → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. **Settings → Actions → General → Workflow permissions** → включить `Read and write permissions` — иначе рабочий процесс не сможет коммитить `fx.js`.
4. Полученный адрес вида `https://<аккаунт>.github.io/<репозиторий>/` вписать в @BotFather: `/newapp` или `/myapps` → Web App URL.

## Как обновляется курс

Прямые запросы к сайтам центробанков браузер не пропускает — сайты не отдают разрешающий заголовок. Поэтому курс приходит иначе: рабочий процесс GitHub раз в сутки забирает его **со стороны сервера** и коммитит в `fx.js`. Страница читает этот файл со своего же домена, где запретов нет.

Каждая страна — по курсу своего центробанка, с запасными адресами на случай отказа основного. Запасной адрес всегда принадлежит **тому же центробанку** или его официальному зеркалу — сторонние агрегаторы курсов не используются, кросс-курсы запрещены.

| Страна | Основной источник | Запасной |
|---|---|---|
| Россия | `cbr.ru/scripts/XML_daily.asp` | `cbr-xml-daily.ru` — зеркало ЦБ РФ |
| Казахстан | `nationalbank.kz/rss/get_rates.cfm` — курсы на дату | `nationalbank.kz/rss/rates_all.xml` — общий поток |
| Беларусь | `api.nbrb.by` | `www.nbrb.by/api` — запасной хост того же API |

Цепочка перебирается сверху вниз до первого успеха, и это работает в двух местах: в ежедневном рабочем процессе и в самом приложении, если `fx.js` почему-то не загрузился. Если по какой-то стране не ответил ни один адрес — её прежний курс сохраняется, помечается `_stale`, и остальные страны всё равно обновляются.

## Курс всегда на момент запроса расчёта

Это правило владельца, и приложение показывает, выполняется оно или нет. Подпись рядом с полями курса читается так:

| Что видно | Что это значит |
|---|---|
| **Курс · 03.09.2026, 14:20** | курс получен прямо сейчас, время указано. Так и должно быть |
| **Курс · 03.09.2026** | из ежедневного `fx.js`, дата сегодняшняя — годится |
| **⚠ курс от 01.09.2026, не на сегодня** | сеть не ответила, показан вчерашний. Поля открываются для правки, в выдаче появляется красное предупреждение, **клиенту такой расчёт не выдаётся** |
| **✏️ впишите курс вручную** | не сработало ничего: ни живой запрос, ни `fx.js` |

Нажатие на подпись перезапрашивает курс.

**Казахстан — исключение: ручной ввод запрещён** (решение владельца 03.09.2026). Поля курса по КЗ заблокированы всегда, при любом исходе загрузки. Курс принимается только от Нацбанка РК — с канала на дату либо с общего потока. Если не ответил ни один, приложение пишет «🔴 курс НБ РК не получен», ставит красное предупреждение в выдаче и такой расчёт клиенту не выдаётся. Единственное действие — нажать на подпись курса и запросить заново.

Потому что: по Казахстану публичные калькуляторы занижают платежи в 2–4 раза, а вписанный от руки курс — самый простой способ незаметно получить ту же ошибку в своём расчёте.

Запустить обновление вручную: вкладка **Actions** → «Курсы валют» → **Run workflow**.

## Как поменять ставку

Порядок обязателен: сначала правка в головном документе «Калькулятор — единая методика РФ КЗ РБ», потом в `rates.js`, потом в материалах клиенту. Наоборот — дефект.

1. Открыть `rates.js`, найти величину.
2. Поменять значение, обновить `checked_at` и `_source`.
3. Если первоисточник не получен — поставить `requires_verification: true`.
4. Закоммитить. Пересобирать `index.html` не нужно.

У каждой величины обязательны три поля: `_source` (акт, статья, редакция), `checked_at` (когда сверяли), `requires_verification`. **Ставка без источника к работе не допускается.**

Проверить, где данные слабые: открыть приложение, в консоли браузера набрать `ENCAR_UNVERIFIED()`.

## Правила расчёта

**Возраст** — от даты изготовления до даты декларации. Подтверждён только год → момент выпуска 1 июля; год и месяц → 15-е число. Единая база для всех стран и всех статей расчёта.

**Льгота по утильсбору в России** — только когда выполнены оба условия: объём **≤ 2 000 см³** И мощность **≤ 160 л.с.**, оба включительно. Превышение любого одного параметра — коммерческий утильсбор целиком.

**Электро и гибриды.** В России идут по отдельной шкале, построенной только по мощности; порог льготы для них 58,84 кВт = 80 л.с. В Казахстане электромобиль (кроме гибридов) — утильплатёж 0 при прямом ввозе и 60 при ввозе из России или Беларуси, регистрационный сбор 0,25 / 25 / 250 МРП. Гибрид под нулевой коэффициент не подпадает — считается по объёму, как ДВС.

**Регистрационный сбор Казахстана** — до 1 года 0,25 МРП, от 1 до 3 лет 50 МРП, старше 3 лет 500 МРП; возраст от даты производства.

**Курс** берётся на момент запроса расчёта.
